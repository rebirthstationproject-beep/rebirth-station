## 1. 마일스톤 목표

v0.1.3 베타 mockup을 **실 서비스로 전환**.

- **마켓플레이스 서버 활성화** (Cloudflare Workers + R2 + D1 + KV)
- **결제 통합** (PayPal + Binance Pay live mode)
- **라이센스 키 Ed25519 발급 + 검증**

- **모바일 PWA selection UI 강화** (페이지 dot + 폴더 breadcrumb + hover ring)
- **LiveSync 양방향 강화** (모바일 → PC RequestExecute ack/nack)
- **Tauri WebDriver E2E CI 통합**
- **자동 업데이트 채널** (tauri-plugin-updater + Ed25519)

## 5. 리스크 분석

### 높음 (High)

| 리스크 | 영향 | 완화 |
|---|---|---|
| **PayPal Live 심사 지연** | 결제 활성화 차단 | T+50일 신청 시작, T+80일 활성화 목표 |
| **Cloudflare Workers 50ms CPU 한도** | API 응답 지연 | 무거운 작업 (스캔, 이미지) → Durable Objects / Queues 분리 |
| **Ed25519 서버 private key 노출** | 라이센스 위조 전면 가능 | Cloudflare Secrets + dual-key 로테이션 정책 |
| **자동 스캔 false-positive** | 정상 큐브팩 반려 | 수동 검토 백업 + 작성자 재신청 워크플로우 |

### 중간 (Medium)

| 리스크 | 영향 | 완화 |
|---|---|---|
| **PayPal Webhook 3초 한도 초과** | 결제 미처리 | 비동기 큐 (Workers Queues) + 즉시 200 응답 |
| **D1 강한 일관성 X** | 결제 직후 라이센스 verify 실패 | Webhook 처리 후 D1 쓰기 + 3초 대기 후 verify 활성 |
| **모바일 PWA Phase 17/18 복잡도** | 일정 지연 | Phase 17만 v0.1.4 진입, Phase 18은 v0.1.5 로 이월 가능 |
| **Cloudflare D1 무료 한도** | 운영 비용 증가 | Paid plan 초기부터 (월 $5) — 비용 §9 참고 |

### 낮음 (Low)

| 리스크 | 영향 | 완화 |
|---|---|---|
| **이메일 발송 실패 (SendGrid)** | 라이센스 수령 지연 | 사용자 별도 `/license/resend` endpoint |
| **Binance Pay 환율 변동** | 가격 표시 혼선 | 가격은 USD 고정, Binance는 USDT 1:1 매칭 |
| **자동 업데이트 사용자 거부** | 신버전 전파 느림 | 강제 업데이트 X, 알림 + 사용자 선택 |
