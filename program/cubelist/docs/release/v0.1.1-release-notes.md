# 🎉 큐브 리스트 v0.1.1 베타

> **Rebirth Station 큐브 리스트** — StreamDeck 동등 + 자유도 확장 + 큐브 무제한.
> v0.1.0 → v0.1.1: Phase 1~5 P2 + Rust OS impl + 사용자 가이드.

## 📥 다운로드

| 패키지 | 사용 시기 |
|---|---|
| **MSI** (`cubelist-pc-helper_0.1.1_x64_en-US.msi`) | 일반 사용자 (Windows Installer 표준) |
| **NSIS Setup** (`cubelist-pc-helper_0.1.1_x64-setup.exe`) | 가벼운 설치 |
| **실행 파일** (`cubelist-pc-helper.exe`) | Portable 또는 개발자 |

### 시스템 요구사항
- Windows 10 이상 (64-bit)
- WebView2 Runtime (Windows 11 기본 설치, Windows 10은 자동 다운로드)

### 설치
1. MSI 또는 NSIS Setup 실행
2. SmartScreen 경고 시 **"추가 정보" → "실행"**
3. 설치 마법사 진행
4. 시작 메뉴에서 **"큐브 리스트"** 실행

> **SmartScreen 안내**: 베타 단계에서는 EV 코드 사이닝 인증서 미적용. 새 출시 평판 누적 과정에서 일시 표시되는 정상 경고. 안전하게 실행 가능.

## ✨ v0.1.1 주요 변경 (요약)

### 🔒 파일 spec 영구 lock
- `.cubeone` v3 / `.cubelist` v3 / `.cubepack` v3 **영구 lock** — 이후 변경 0 보장
- 어떤 큐브 파일이든 향후 모든 버전의 큐브 리스트에서 호환

### 🎯 P1 11 신규 액션 (StreamDeck 100% 호환)
| 액션 | 설명 |
|---|---|
| `media_key` | 미디어 키 (play/pause/next/prev/stop/volume±/mute) |
| `page_navigate` / `page_jump` | 페이지 이동 / 특정 페이지 점프 |
| `folder_up` / `folder_open` | 폴더 이동 |
| `window_close` | 활성 창 닫기 (Alt+F4) |
| `system_sleep` | 시스템 절전 (Tier 3 동의 후) |
| `system_actionbar_toggle` | 작업 표시줄 표시/숨김 |
| `audio_play` | 오디오 클립 재생 |
| `hotkey_toggle` | 토글 단축키 (예정) |
| `profile_rotate` | 큐브 리스트 회전 |

### ⏰ 동적 큐브 (P2)
- `live_clock` — 디지털 시계 (1초/30초/1분 갱신)
- `live_timer` — 카운트다운 타이머
- `live_gauge` — 게이지 (수치 + 색상 바 자동)
- `live_battery` — 배터리 잔량 (시스템 자동 / 수동)

### 🔄 `.streamDeckProfile` → `.cubepack` 변환기 (신규)
- DefaultProfiles 13개 디바이스 프로필 일괄 변환
- 디바이스별 그리드 자동 매핑 (Mini 3×2 / Std 5×3 / XL 8×4 / Plus 4×2 / Neo 4×2)
- StreamDeck 사용자 배치 그대로 재현
- **검증: 13 .cubepack / 742 큐브 변환 성공**

### 🎨 StreamDeck LCD 톤 시각 강화
- 큐브 셀 **pure black LCD 배경** + inset shadow = 패널 깊이감
- 선택 시 **노란 LED 글로우** (StreamDeck 키 활성 모방)
- 그리드 베젤 (#0a0a0a) + inset shadow
- 단색 placeholder PNG 자동 가시화 (invert filter)

### 🖼️ 이미지 변환 호환 (30% → 11% 미렌더링)
- SVG 단색 회색 자동 정규화
- PNG_TINY 회피 (작은 placeholder → SVG 대체)
- 액션별 이미지 매칭 정확도 +51건 향상

### 🔐 Tier 2/3 사용자 동의 시스템
- 위험 액션 실행 전 동의 prompt
- 한 번 동의 → localStorage 영속화, 이후 자동 통과
- 설정에서 동의 초기화 가능

### 🔍 라이브러리 검색 UX
- 사이드바 상단 검색 input (큐브 리스트·큐브 동시 매칭)
- 검색 시 자동 펼치기
- 클리어 버튼

## 🚀 빠른 시작

### 1. StreamDeck 플러그인 변환
1. TopBar **📥 플러그인 변환** 클릭
2. `.streamDeckPlugin` 파일 선택
3. 자동 변환 → 라이브러리 등록

### 2. 라이브러리 폴더 등록
1. TopBar 우상단 **📁 폴더 아이콘** 클릭
2. 폴더 경로 입력 (예: `C:\Users\<이름>\Downloads\플러그인\CUBE`)
3. 사이드바에 큐브 리스트 트리 표시

### 3. 큐브 그리드 배치
- 사이드바 큐브 → 그리드 슬롯 드래그
- 또는 빈 슬롯 클릭 → 즉시 생성

### 4. 큐브 실행
- 더블클릭 또는 인스펙터 **▶ 테스트 실행**

자세한 사용법: [USER_GUIDE.md](../USER_GUIDE.md)
