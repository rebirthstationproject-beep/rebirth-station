## 2A — PC 마무리 폴리시 (즉시 실행)
1. **TopBar 정돈** ✓간격(`.topbar-right` gap 8px — 완료) + 버튼 그룹 구분선: [가져오기·내보내기] | [+ 플러그인·플러그인 변환] | [폴더·팩 정보] | [▶ 작동] | [언어·설정] — 1px 무채색 세로선.
2. **폴더로 드래그 인**: 큐브를 folder 큐브 위에 드롭 → 그 폴더의 cube_ids에 추가(루트에서 자동 격리됨). folder를 folder에 넣는 것은 v1 금지(중첩 1단). store 액션 `addCubeToFolder(listId, folderId, cubeId)` 신설(불변 갱신, 이미 다른 폴더 소속이면 이전 폴더에서 제거 후 이동).
3. **Ctrl+클릭 다중 선택 + 일괄 삭제**: CubeMakerCenter 로컬 Set 상태. Ctrl+클릭=토글(is-in-selection 스타일 재사용), 일반 클릭=단일 선택+다중 해제, Delete=선택 전체 삭제(confirm에 개수 표기). 다중 선택 상태에서 드래그 시 v1은 드래그한 큐브만 이동(그룹 이동은 2A+).

## 2A-2 — 리스트 빌더 재설계 (사용자 지시 2026-06-10, 즉시 실행)
> "위 아래를 나누고 위에는 리스트 배치 화면, 아래는 전체 큐브가 보이도록 해서 왼쪽 경로에서 누르면 아래에 큐브가 보이고 그걸 드래그 앤 드롭으로 내려놓을 수 있게"

1. **상하 분할 레이아웃**: 큐브 리스트 만들기 탭 = 위(리스트 배치 그리드, 기존 DraftPageTabs+GridArea) + 아래(큐브 팔레트 패널 ~220px).
2. **빈 상태 제거**: 탭 진입 시 draft 없으면 빈 draft("새 리스트") 자동 생성 → 항상 배치 화면 표시.
3. **큐브 팔레트**: 아래 패널에 선택된 소스 리스트의 큐브들을 소형 타일(64px+라벨)로 가로 스크롤 표시. 소스 선택 = 왼쪽 사이드바 트리 클릭(리스트 만들기 탭에서는 폴더 클릭이 팔레트 소스 변경으로 동작) + "전체"(라이브러리 풀).
4. **팔레트 → 배치 그리드 DnD**: 팔레트 타일을 위 그리드 슬롯/빈 슬롯에 드롭 = 해당 큐브 **복사**(새 id, 원본 불변)로 배치. 같은 DndContext 공유(상위에서 단일 컨텍스트, CubeGrid 내부 컨텍스트는 draft 모드에서 외부 위임). 기존 그리드 내 정렬 DnD는 유지.
5. 메인 탭 상태(main_tab)를 store로 승격 — 사이드바가 탭에 따라 동작 분기(큐브 만들기=리스트 선택 / 리스트 만들기=팔레트 소스 선택).
