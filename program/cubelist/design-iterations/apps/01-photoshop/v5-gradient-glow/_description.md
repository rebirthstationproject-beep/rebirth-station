# Photoshop · v5 Gradient Glow

## 디자인 의도
- **사이버펑크 / 네온 글로우** — 다크 + 그라데이션 발광
- 배경: `#001E36` 다크 + radial glow `#31A8FF` 0.5 → 0
- 액션: 청록색 그라데이션 stroke `#7FD0FF → #1E88E5` + filter blur 1.5
- 이중 stroke (블러 발광 레이어 + 선명한 stroke)
- 여백 12.5% (안쪽 48px)

## 차별점
- 가장 화려함 / 미래적 / 게이밍
- 다크모드 + RGB 라이팅 컴퓨터 분위기
- 스트리밍/게임 사용자 친화
- 큐브 셀이 발광하는 느낌
